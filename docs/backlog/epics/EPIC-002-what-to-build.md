## Outcome

"I want a better dashboard" becomes a filled idea, a set of answered clarifications, and either a promoted epic/story or a recorded `rejected` — without the builder inventing structure by hand.

## Stories

- US-002 — Clarify an item into a bounded question set
- US-003 — Promote an idea along promoted_to
- US-004 — Record a kill verdict on an idea
- US-005 — Answer clarifications in the browser

## Success metrics

- A new idea can be clarified, promoted, or rejected without editing frontmatter by hand
- `pb clarify` writes answers back as acceptance criteria, a business-rule, or a logged open question
- The UI can start the same loop from a sentence
